## 1. 專案緣起：從「旅館島」到「資管島」

本專案以研習提供的 `HTL_island_navigator-main.zip` 為參考範本。該範本是 **國立高雄餐旅大學旅館管理系** 的 3D 導覽網站：

| 範本（HTL Island Navigator） | 說明 |
|---|---|
| 呈現形式 | 3D 六角島嶼城市（Three.js），20 座主題島、133 個細項，加上 2D 四年時間軸 |
| 資料原則 | 所有事實只取自系所官網，檔案內附同步／驗證腳本 |
| 規模 | 約 22 MB、數十個 JS 模組（角色操控、多人廣場、高雄地景、語音、遊戲化護照等） |

範本有大量與高餐大綁定的內容（高雄地景、校園雕塑、教師語音、多人連線伺服器），直接逐檔替換的成本高、也容易殘留錯誤資訊。因此試作版 **保留範本的核心概念**，用精簡的程式重新實作：

- ✅ 保留：六角群島地圖、島 = 主題／建築 = 資訊卡、島際學習動線、2D 時間軸、只用官網資料並附來源連結
- ⏸️ 暫不納入：角色走動、多人廣場、語音導覽、遊戲化任務、城市地景（可於正式版再評估）

## 2. 「地圖」適合呈現靜宜資管嗎？

適合，理由是資管系的資訊本身就有「空間」與「路徑」兩種結構：

1. **空間感**：7 間實驗室實際位於主顧樓 403–415；四大學程、師資、實習彼此相連，像群島一樣可以「逛」。
2. **路徑感**：學生從大一學習家族 → 大二選學程 → 大三畢業專題 → 大四實習／升學，是一條可以在地圖上「走」的路線。
3. **關聯性**：老師 ↔ 實驗室 ↔ 學程 ↔ 證照 ↔ 出路的關係，用島與橋連起來比單純的選單更容易理解。

因此本試作版提供兩種檢視：**3D 群島地圖**（看全貌、看關聯）與 **學習路徑**（依大一～碩士班排列）。

### 功能

- **3D 群島**：拖曳旋轉、滾輪縮放；點島嶼或建築，鏡頭飛過去並在側欄展開資訊卡
- **依學年亮起**：選「大一／大二／大三／大四／碩士班」，相關建築亮起、其他淡出
- **全文搜尋**：可用課程、老師、實驗室、證照名稱等關鍵字搜尋
- **學習路徑**：2D 五欄時間軸，點卡片回到 3D 地圖對應位置
- **分享連結**：網址 `#島嶼id` 或 `#項目id` 可直接開啟（例：`#lab-405`、`#p-erp`）
- **手機版**：上方地圖、下方資訊卡

## 4. 檔案結構

```
PUMAP_CSIM/
├── index.html        # 頁面骨架
├── style.css         # 版面樣式（靜宜藍主色）
├── app.js            # 3D 場景、互動、搜尋、學習路徑
├── data.js           # ★ 所有系所資料（要修改內容只需改這個檔）
├── assets/favicon.svg
├── vendor/three/     # Three.js r160（MIT，取自範本）
├── _headers          # Cloudflare Pages 安全標頭
└── README.md
```

### 如何修改內容

所有文字都在 `data.js`：

- `ISLANDS`：每座島的 `name`、`icon`、`color`、`summary` 與 `items`（建築）
- 每個 item：`name`、`facts`（條列事實）、`src`（對應 `SOURCES` 的來源鍵）、`stages`（出現在哪些學年）
- `LINKS`：島與島之間的連線
- **原則**：只放官網上查得到的內容，並在 `src` 標明來源頁面
